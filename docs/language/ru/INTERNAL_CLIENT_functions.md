Веб-клиент выполняет функцию JavaScript, имя которой указано в действии или операторе-действии [`INTERNAL CLIENT`](INTERNAL_operator.md#client). Способ предоставления функции и её поиск по имени описаны в статье [Клиентские модули JavaScript](Client_JavaScript_modules.md#named-exports-and-auto-registration).

### Аргументы и результат {#arguments-and-result}

Веб-клиент сначала передаёт параметры вызова, а затем контроллер. При выполнении действия на форме передаётся [контроллер формы](Form_and_navigator_controllers.md#the-form-controller). При выполнении действия в навигаторе передаётся [контроллер навигатора](Form_and_navigator_controllers.md#navigator-controller).

Число объявленных параметров клиент определяет по свойству `length` функции. Подсчёт останавливается перед первым параметром со значением по умолчанию или остаточным параметром (`...args`). Если в подсчёт вошёл параметр после контроллера, клиент передаёт в него функцию обратного вызова для успешного завершения. Если в подсчёт вошёл и второй параметр после контроллера, клиент передаёт в него функцию обратного вызова для ошибки.

Если функция объявляет параметры для обратного вызова, для завершения она должна ровно один раз вызвать одну из переданных функций, в том числе при ошибке. Результат передаётся в функцию успешного завершения, а ошибка — в функцию для ошибки. До этого вызов остаётся незавершённым.

Если в подсчёт не вошёл ни один параметр для обратного вызова, клиент преобразует возвращённое значение как есть. Выполнения возвращённого `Promise` клиент не ждёт.

```js
function reload(controller) { controller.exec('refreshData'); }

function readClipboard(controller, resolve, reject) {
    navigator.clipboard.readText().then(resolve, reject);
}
```

### Запросы через контроллер {#controller-requests}

Форма выполняет запросы через свой контроллер по одному. Запрос из функции JavaScript выполняется после завершения действия, вызвавшего эту функцию. На запрос списка подсказок ([`getValues`](Form_and_navigator_controllers.md#looking-up-values)) форма может ответить вне очереди.

Если действие ждёт завершения функции (`WAIT` или `TO`), запрос, который функция поставила в очередь формы, может выполниться только после её завершения. Если функция ждёт этот запрос, ни функция, ни действие не могут завершиться.

Веб-клиент начинает следующий вызов `CLIENT` на той же форме или в том же навигаторе, когда текущая асинхронная функция сообщает о завершении через один из обратных вызовов. Если действие ждёт завершения следующего вызова, запрос текущей функции из очереди формы может выполниться только после того, как она сообщит о завершении.
