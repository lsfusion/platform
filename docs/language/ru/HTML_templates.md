HTML-шаблон — это разметка, которая задаёт расположение дочерних компонентов контейнера формы в веб-клиенте или элементов окна навигатора в настольном веб-клиенте. Для контейнера её задают [атрибутом дизайна `custom`](DESIGN_statement.md#containerprops), для окна навигатора — [опцией окна `CUSTOM`](WINDOW_statement.md#custom).

### HTML-разметка {#markup}

Платформа вставляет HTML-разметку приложения как есть, отдельно обрабатывая места шаблона. Атрибуты-обработчики, например `onclick` и `onerror`, срабатывают при соответствующих событиях. Теги `<script>` остаются в разметке без выполнения кода.

Шаблон работает без React и не получает данных. Он может размещать представления по имени. Остальную разметку задаёт приложение.

Литерал шаблона может содержать не более 65 535 байт в модифицированной кодировке UTF-8. Платформа отклоняет более длинный литерал в месте объявления. Для разметки большего размера используйте шаблон, вычисляемый свойством.

### Места HTML-шаблона {#template-places}

`<Platform:name>` обозначает место, куда платформа помещает представление с указанным именем. Платформа заменяет тег самим представлением, без отдельного оборачивающего элемента. Дочерний компонент или элемент навигатора без места в шаблоне не отображается.

Каждое место записывается одним открывающим тегом с именем. Закрывающие и самозакрывающиеся теги мест считаются ошибкой. Префикс `Platform:` можно писать в любом регистре. Регистр имени после него должен совпадать с оригиналом. Для каждого имени можно указать только одно место.

#### Места в контейнере формы {#form-container-places}

В качестве имени указывается [идентификатор компонента](DESIGN_statement.md#selector) из дизайна, например `PROPERTY(qty)` для компонента свойства. Место для компонента из другой части формы остаётся пустым.

Заголовки и значки дочерних компонентов и самого контейнера недоступны шаблону как данные. Платформа рисует заголовок и комментарий свойства, отображаемого в потоке контейнера, в отдельных местах, например `<Platform:PROPERTY(qty).caption>` и `<Platform:PROPERTY(qty).comment>`. Эти места можно включить в свою разметку, например в заголовок раздела. При `inline = FALSE` заголовок и комментарий входят в представление свойства. У остальных дочерних компонентов заголовок входит в их представление. Заголовок и значок самого контейнера платформа рисует рядом с ним, за пределами шаблона.

Чтобы добавить дочерний компонент в шаблон, нужно изменить его строку. Строка шаблона принадлежит объявившему её модулю и заменяется только целиком.

#### Места в окне навигатора {#navigator-window-places}

Платформа помещает в отведённое место стандартную кнопку элемента навигатора. Кнопка размещается независимо от того, задана ли для элемента опция `NOCUSTOM`.

В литерале платформа разрешает имя в [пространствах имён](../paradigm/Naming.md#namespace) модуля, поэтому элемент навигатора должен быть уже объявлен. В шаблоне, вычисляемом свойством, сразу указывается [каноническое имя](../paradigm/Naming.md#canonicalname) элемента.

Этот шаблон размещает кнопки ранее объявленных элементов навигатора `items` и `partners` в окне `System.toolbar`, в котором они отображаются.

```lsf
EXTEND WINDOW System.toolbar CUSTOM
    '<div class="menu"><div class="menu-head">Справочники</div><Platform:items><Platform:partners></div>';
```

### Ошибки в местах шаблона {#place-errors}

Платформа проверяет места шаблона, заданного литералом, при сборке формы или обработке инструкции `WINDOW` или `EXTEND WINDOW`. Ошибкой считается место без имени, повторное указание имени, закрывающий или самозакрывающийся тег. Ошибка также возникает, если на форме нет компонента с указанным именем или если имя элемента навигатора не разрешается.

Шаблон, вычисляемый свойством, веб-клиент проверяет при отрисовке. Сообщения об отсутствующем, повторном или неизвестном имени выводятся в самом месте и в консоли браузера. Сообщения о закрывающем и самозакрывающемся тегах выводятся только в консоли, поскольку браузер уже обработал эти теги. Ошибка в месте для элемента навигатора, назначенного другому окну, также выводится в самом месте и в консоли.
