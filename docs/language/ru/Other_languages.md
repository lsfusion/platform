В этом разделе описаны интерфейсы для кода, разметки и стилей на других языках, в том числе для JavaScript, HTML и CSS в клиенте и Java и JRXML на сервере приложений.

- В подразделе [JavaScript](Client_JavaScript_modules.md) описаны клиентские модули, в которых хранится весь клиентский код, включая компоненты React. Здесь также описаны [функции отображения](Render_functions.md) и [функции редактирования](Edit_functions.md) классических пользовательских представлений и [контроллеры формы и навигатора](Form_and_navigator_controllers.md), которые получает любое представление на JavaScript. В его подразделе [React](React_views.md) описано, что получает от формы и что вызывает компонент React, который рисует контейнер, компонент или окно клиента.
- В подразделе [HTML](HTML_templates.md) описана разметка шаблонов контейнеров формы и окон навигатора.
- В подразделе [CSS](CSS_view_styles.md) описаны стили форм, элементов навигатора и окон, которые отображает веб-клиент.
- В подразделе [Java](Java_integration_API.md) описаны классы и методы для обращения к lsFusion из подклассов `InternalAction` и из [компонентов Spring на основе `EventServer`](Custom_Spring_bean_EventServer.md).
- В подразделе [JRXML](JRXML_report_templates.md) описаны поля, параметры подотчетов и разметка шаблонов отчетов.
