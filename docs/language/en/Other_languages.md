This section describes the interfaces used by code and markup written in other languages, including JavaScript and HTML in the client and Java in the application server.

- [JavaScript](Client_JavaScript_modules.md) covers the client modules that hold all client code, including React components. It also covers the [render functions](Render_functions.md) and [edit functions](Edit_functions.md) of classic custom views and the [form and navigator controllers](Form_and_navigator_controllers.md) that any view written in JavaScript receives. Its [React](React_views.md) subsection describes what a React component that draws a container, a component or a client window receives from the form and calls.
- [HTML](HTML_templates.md) covers the markup of templates for form containers and navigator windows.
- [Java](Java_integration_API.md) covers the classes and methods for accessing lsFusion from `InternalAction` subclasses and from [Spring beans based on `EventServer`](Custom_Spring_bean_EventServer.md).
