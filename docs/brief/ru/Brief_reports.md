## Печатное представление

*Отчет* — это шаблон, при подстановке данных в который строится документ. [Печатное представление](../paradigm/Print_view.md) формы состоит из набора отчетов, каждому из которых отведен свой набор [групп объектов](../paradigm/Form_structure.md#objects) формы; как группы разбиваются по отчетам и как опция `SUBREPORT` у группы выделяет ее в отдельный отчет — *подотчет* — описано в [построении иерархии отчетов](../paradigm/Print_view.md#buildhierarchy).

Что происходит с документом, выбирают параметры [оператора `PRINT`](../language/PRINT_operator.md), у которых есть два варианта. `MESSAGE` показывает форму пользователю сообщением: свойства корневой группы становятся его заголовком, а таблица под ним берется из ПЕРВОЙ дочерней группы — форма без дочерней группы дает пустую таблицу, а всякая дочерняя группа после первой не попадает в результат. Второй вариант — [интерактивный](../paradigm/In_a_print_view_PRINT.md#interactive): `previewMode` — это либо `PREVIEW`, значение по умолчанию, когда отчет показывается пользователю, либо `NOPREVIEW`, когда он напрямую уходит на принтер (`TO <выражение>` выбирает принтер), а формат — `PDF`, `DOC`, `DOCX`, `XLS`, `XLSX`, `HTML`, `RTF` — вместе с `TO <свойство>` записывает документ в файл на сервере. `SHEET` и `PASSWORD` доступны для `XLS` и `XLSX`.

```lsf
FORM printOrder
    OBJECTS o = Order
    PROPERTIES(o) date, nameCustomer

    OBJECTS d = OrderDetail SUBREPORT
    PROPERTIES(d) nameSku, quantity
    FILTERS order(d) = o
;

print (Order o) { PRINT printOrder OBJECTS o = o DOCX TO orderFile; }
```

## Дизайн отчёта

[Дизайн отчета](../paradigm/Report_design.md) — то, как отчет раскладывается в документе. Отчет описывает [шаблон](../paradigm/Report_design.md#template) — [файл `.jrxml`](../paradigm/Report_design.md#format) технологии JasperReports, который платформа ищет в classpath сервера по имени, производному от канонического имени формы; полями шаблона служат свойства формы, их имена и типы совпадают. Точные правила именования и цена ошибки в имени — [Правила: отчеты](../rules/Rules_reports.md).

Своего шаблона может и не быть: если хотя бы один не найден, платформа строит [автоматический дизайн](../paradigm/Report_design.md#auto) по структуре формы. Шаблон задается и явно, свойством с именем файла или самим файлом: блок `REPORT` [инструкции `FORM`](../language/FORM_statement.md) — для верхнего отчета, `REPORTS` (синоним `REPORTFILES`) — для перечисленных групп объектов, выражение после `SUBREPORT` в [блоке объектов](../language/Object_blocks.md) — для своей группы.
