## Разработка исходного кода

Разработка — это работа с исходным кодом приложения `.lsf` в его репозитории через плагин навыков или прямое подключение к серверу документации. Код проверяется диагностикой IDE без запуска приложения, пробным запуском (dry run) или запуском сервера, а поведение — выполнением в тестовом приложении. Изменение `.lsf` требует перезапуска сервера приложений; какие ещё изменения режим разработки подхватывает без перезапуска, говорит навык `lsfusion-dev`.

Навыки `lsfusion-ai-skills`, если они установлены, содержат порядок работы для локальной настройки, запуска сервера, вызовов на работающем сервере и развёртывания. Плагин навыков подключается как `dev` (`?via=dev&with=skills`); `with=skills` на ответ не влияет.
