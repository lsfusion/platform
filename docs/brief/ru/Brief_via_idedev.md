## Инструменты проекта IntelliJ

Этот вид расширяет [`via_dev`](Brief_via_dev.md): MCP-инструменты плагина IntelliJ добавляют структуру открытого проекта и анализ IDE — `lsfusion_find_elements` для объявлений, диагностику IDE для ошибок без запуска приложения, `lsfusion_set_meta_visibility` для кода, порождённого метакодом.

Объявления, порождённые [использованием метакода](../paradigm/Metaprogramming.md), видны анализу IDE только в развёрнутом коде — в файле, где применён метакод. Это может быть требуемый модуль, а не редактируемый файл.
