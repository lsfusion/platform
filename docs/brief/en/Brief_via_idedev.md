## IntelliJ project tools

This kind extends [`via_dev`](Brief_via_dev.md): the IntelliJ plugin's MCP tools add the opened project's structure and IDE analysis — `lsfusion_find_elements` for declarations, IDE diagnostics for errors without starting the application, `lsfusion_set_meta_visibility` for code generated by metacode.

Declarations generated by a [metacode usage](../paradigm/Metaprogramming.md) exist for IDE analysis only in expanded code, in the file that applies the usage, which may be a required module rather than the file being edited.
