Операторы выделения создают [свойства](Properties.md), сообщающие о выделении пользователем строк и колонок в [группе объектов](Form_structure.md#objects):

-   свойство набора объектов возвращает `TRUE`, если этот набор сейчас выделен (отмечен) пользователем в группе, и `NULL` в противном случае;
-   свойство группы в целом возвращает `TRUE`, если пользователь выделил в группе строки, и `NULL` в противном случае;
-   свойство колонки возвращает `TRUE`, если эта колонка сейчас выделена пользователем, и `NULL` в противном случае.

Пока пользователь не выделил ни одной строки, свойство набора объектов возвращает `TRUE` для текущей строки группы объектов; когда выделение появилось - для выделенных строк, прошедших все критерии фильтрации на форме. Выделенные строки задаются диапазоном в текущем порядке группы объектов, поэтому при изменении порядка набор выделенных строк пересчитывается. Колонка, в которой находится текущая ячейка, считается выделенной.

### Язык

Для объявления этих свойств используются операторы [`SELECT`, `SELECT ACTIVE` и `SELECT PROPERTY`](../language/Object_group_operator.md).

### Примеры

```lsf
CLASS Store;
name = DATA STRING[100] (Store);

FORM stores
    OBJECTS s = Store
    PROPERTIES(s) name
;
selectedCount 'Количество выделенных складов' () = GROUP SUM 1 IF [ SELECT stores.s](Store s);
selectActive 'Выделение задано' () = [ SELECT ACTIVE stores.s]();
nameSelected 'Свойство name выделено' () = [ SELECT PROPERTY stores.name(s)]();
```
