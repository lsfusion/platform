Оператор вида отображения создаёт [свойство](Properties.md), значением которого является текущий *вид отображения*, в котором [группа объектов](Form_structure.md#objects) показывается пользователю: в виде таблицы, сводной таблицы, карты, календаря или пользовательского представления.

### Сводная таблица {#pivot}

Когда сводная таблица открывается без заранее выбранных колонок-мер (значений), платформа сама выбирает набор по умолчанию: [рабочий параметр](Working_parameters.md) `pivotOnlySelectedColumn`, установленный в `false` (по умолчанию), предлагает в качестве мер все свойства числовых типов; установленный в `true` — предзаполняет только числовые свойства, производные от `COUNT(...)`, и то свойство, на котором пользователь находился при переключении в сводный вид, если оно тоже числовое. Рабочий параметр `useClusterizeInPivot` включает виртуализированный рендеринг рядов (в DOM держатся только видимые в данный момент ряды) после того, как пользователь нажимает "Показать все" — где иначе целиком отрисовывался бы очень большой результат; обычный постраничный вид никогда не виртуализируется. По умолчанию выключен, и даже "Показать все" рендерит каждый ряд напрямую.

### Язык

Для объявления свойства, возвращающего текущий вид отображения группы объектов, используется [оператор `VIEWTYPE`](../language/Object_group_operator.md).

### Примеры

```lsf
CLASS Store;
name = DATA STRING[100] (Store);

FORM stores
    OBJECTS s = Store
    PROPERTIES(s) name
;
isPivot 'Склады в виде сводной таблицы' () = [ VIEWTYPE stores.s]() == ListViewType.pivot;
```
